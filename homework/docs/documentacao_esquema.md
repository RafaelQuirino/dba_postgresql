| Tabela     | Restrição usada                      |
|------------|--------------------------------------|
| `producao` | PRIMARY KEY                          |
| `pessoa`   | PRIMARY KEY                          |
| `equipe`   | PRIMARY KEY e FOREIGN KEY            |
